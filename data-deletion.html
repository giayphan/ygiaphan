Data Deletion / ลบข้อมูลของคุณ

Yêu cầu xoá dữ liệu cá nhân khỏi ygiaphan

📌 ข้อมูลที่เราเก็บ

  • ชื่อ + อีเมล (จาก Facebook Login)
  • ประวัติการเข้าสู่ระบบ
  • คอมเมนต์ / การแจ้งโอน (ถ้ามี)

เราไม่เก็บรหัสผ่าน Facebook, ไม่โพสต์แทนคุณ, ไม่แชร์ข้อมูลกับบุคคลที่สาม

✉️ วิธีขอลบข้อมูล

  1. ส่งอีเมลมาที่ giayphan@gmail.com
  2. หัวข้อ: Data Deletion Request
  3. ระบุ: ชื่อบัญชี Facebook + อีเมลที่ใช้ login

เราจะลบข้อมูลของคุณทั้งหมดภายใน 30 วัน และส่งอีเมลยืนยันกลับ

✉️ ส่งคำขอลบข้อมูล

🔒 ลบสิทธิ์เข้าถึงจากฝั่ง Facebook

คุณยกเลิกสิทธิ์ของแอป ygiaphan ได้ตลอดเวลาที่:

Facebook → Settings → Apps and Websites → ค้นหา ygiaphan → กด Remove
